Module 11

Object-Oriented Design (OOD)

Design class hierarchies, not distributed systems. OOD interviews appear at L4 at Amazon and in coding rounds at Google — the output is a UML class diagram and working Java code. Master SOLID principles, six key design patterns, and four complete OOD problems.

⏱️ 45 min read

OOD vs System Design — Know Which Interview You Are In

These are two fundamentally different interview types that require completely different outputs.

OOD vs System Design: Key Differences
DimensionObject-Oriented DesignSystem Design
OutputUML class diagram + Java/C++ codeArchitecture diagram with boxes and arrows
ScopeSingle application or libraryDistributed system across many services
FocusClasses, interfaces, inheritance, polymorphismScale, availability, consistency, partitioning
When askedL4 at Amazon, coding rounds at GoogleL5+ system design rounds
Key question"Design a parking lot" → classes"Design Uber" → services, databases, queues
The OOD Interview Framework (use every time):
  1. Requirements: Clarify use cases, constraints, what must and must not be designed.
  2. Identify Nouns: Every noun in the requirements is a candidate class or attribute.
  3. Identify Verbs: Every verb is a candidate method. Park → park(vehicle). Exit → exit(licensePlate).
  4. Define Relationships: Is-a (inheritance), Has-a (composition), Uses-a (association).
  5. Draw Class Diagram: Abstract base classes, interfaces, composition hierarchy.
  6. Implement Core Logic: Write the two or three most interesting methods in full.

SOLID Principles — The OOD Foundation

Interviewers expect you to name and apply these. They rarely ask "what is SOLID?" — instead they ask "why did you design it this way?" and the answer traces back to one of these five principles.

SOLID Principles Quick Reference
PrincipleOne-line ruleReal example
S — Single Responsibility One class, one reason to change. FeeCalculator calculates fees only; it does not also issue tickets.
O — Open/Closed Open for extension, closed for modification. Add a new ElectricVehicle type by extending Vehicle — no existing code changes.
L — Liskov Substitution Subclasses must be substitutable for their base class. Any code that works with Vehicle must work with Car or Truck without modification.
I — Interface Segregation Prefer small focused interfaces over fat ones. Split a fat ParkingOperations interface into Parkable and Payable — classes only implement what they need.
D — Dependency Inversion Depend on abstractions, not concretions. ParkingLot depends on FeeStrategy interface, not HourlyFeeCalculator directly — swap fee strategies without touching the lot.

Design Pattern Quick Reference for OOD Interviews

You do not need all 23 GoF patterns. These six cover 90% of OOD interview requirements.

Key Design Patterns for OOD Interviews
PatternIntentClassic use cases
Singleton Ensure exactly one instance exists. Database connection pool, application config manager, logging service.
Factory / Factory Method Create objects without specifying the exact concrete class. VehicleFactory.create(type) returns Car, Truck, or Motorcycle.
Strategy Define a family of interchangeable algorithms. Sorting strategies, payment methods, fee calculation rules, dispatch algorithms.
Observer Notify multiple dependents when an object's state changes. Event listeners, notification systems, pub/sub, elevator floor arrival alerts.
Decorator Wrap an object to add behaviour without changing its class. Logging around a service, compression/encryption layers, UI widget enhancements.
State Alter object behaviour based on internal state — each state is a class. Vending machine states (IDLE, HAS_MONEY, DISPENSING), elevator states, order lifecycle.

OOD Problem 1: Parking Lot System

Requirements: Multiple levels, each with multiple spots. Spot types: motorcycle, compact, large. Vehicles: motorcycle (motorcycle spots only), car (compact or large), truck (large only). Issue ticket on entry with timestamp; calculate fee on exit using hourly rates by vehicle type. Support: check spot availability, find nearest spot, full/not-full status.

// ── VehicleType.java / SpotType.java ──────────────────────────────
public enum VehicleType { MOTORCYCLE, CAR, TRUCK }
public enum SpotType    { MOTORCYCLE, COMPACT, LARGE }

// ── Vehicle.java (abstract) ───────────────────────────────────────
public abstract class Vehicle {
    private final String licensePlate;
    private final VehicleType type;

    public Vehicle(String licensePlate, VehicleType type) {
        this.licensePlate = licensePlate;
        this.type = type;
    }

    public String getLicensePlate() { return licensePlate; }
    public VehicleType getType()    { return type; }

    /** Each subclass knows which spot sizes it fits into. */
    public abstract boolean canFitInSpot(SpotType spotType);
}

// ── Car.java ──────────────────────────────────────────────────────
public class Car extends Vehicle {
    public Car(String licensePlate) { super(licensePlate, VehicleType.CAR); }

    @Override
    public boolean canFitInSpot(SpotType spotType) {
        return spotType == SpotType.COMPACT || spotType == SpotType.LARGE;
    }
}

// ── Motorcycle.java ───────────────────────────────────────────────
public class Motorcycle extends Vehicle {
    public Motorcycle(String licensePlate) {
        super(licensePlate, VehicleType.MOTORCYCLE);
    }

    @Override
    public boolean canFitInSpot(SpotType spotType) {
        return spotType == SpotType.MOTORCYCLE;
    }
}

// ── Truck.java ────────────────────────────────────────────────────
public class Truck extends Vehicle {
    public Truck(String licensePlate) { super(licensePlate, VehicleType.TRUCK); }

    @Override
    public boolean canFitInSpot(SpotType spotType) {
        return spotType == SpotType.LARGE;
    }
}

// ── ParkingSpot.java ──────────────────────────────────────────────
public class ParkingSpot {
    private final int spotId;
    private final SpotType type;
    private Vehicle parkedVehicle; // null when available

    public ParkingSpot(int spotId, SpotType type) {
        this.spotId = spotId;
        this.type = type;
    }

    public boolean isAvailable()              { return parkedVehicle == null; }
    public boolean canAccept(Vehicle vehicle) { return isAvailable() && vehicle.canFitInSpot(type); }
    public void park(Vehicle vehicle)         { this.parkedVehicle = vehicle; }
    public void vacate()                      { this.parkedVehicle = null; }
    public int getSpotId()                    { return spotId; }
    public SpotType getType()                 { return type; }
}

// ── ParkingLevel.java ─────────────────────────────────────────────
public class ParkingLevel {
    private final int levelNumber;
    private final List<ParkingSpot> spots;

    public ParkingLevel(int levelNumber, List<ParkingSpot> spots) {
        this.levelNumber = levelNumber;
        this.spots = spots;
    }

    /**
     * Finds the first available spot that fits the vehicle.
     * Returns empty Optional if the level is full for this vehicle type.
     */
    public Optional<ParkingSpot> findAvailableSpot(Vehicle vehicle) {
        return spots.stream()
            .filter(spot -> spot.canAccept(vehicle))
            .findFirst();
    }

    public boolean isFull() {
        return spots.stream().noneMatch(ParkingSpot::isAvailable);
    }
}

// ── ParkingTicket.java ────────────────────────────────────────────
public class ParkingTicket {
    private final String ticketId;
    private final Vehicle vehicle;
    private final ParkingSpot spot;
    private final Instant issuedAt;

    public ParkingTicket(Vehicle vehicle, ParkingSpot spot, Instant issuedAt) {
        this.ticketId = UUID.randomUUID().toString();
        this.vehicle  = vehicle;
        this.spot     = spot;
        this.issuedAt = issuedAt;
    }

    public Vehicle getVehicle()  { return vehicle; }
    public ParkingSpot getSpot() { return spot; }
    public Instant getIssuedAt() { return issuedAt; }
}

// ── FeeCalculator.java ────────────────────────────────────────────
public class FeeCalculator {
    private static final Map<VehicleType, BigDecimal> HOURLY_RATES = Map.of(
        VehicleType.MOTORCYCLE, new BigDecimal("1.50"),
        VehicleType.CAR,        new BigDecimal("3.00"),
        VehicleType.TRUCK,      new BigDecimal("5.00")
    );

    /**
     * Calculates parking fee based on vehicle type and duration.
     * Minimum charge is 1 hour; partial hours are rounded up.
     */
    public static BigDecimal calculate(ParkingTicket ticket, Instant exitTime) {
        long hoursParked = Duration.between(ticket.getIssuedAt(), exitTime).toHours();
        long billableHours = Math.max(1, hoursParked); // minimum 1 hour
        BigDecimal rate = HOURLY_RATES.get(ticket.getVehicle().getType());
        return rate.multiply(BigDecimal.valueOf(billableHours));
    }
}

// ── ParkingLot.java (orchestrator) ───────────────────────────────
public class ParkingLot {
    private final List<ParkingLevel> levels;
    private final Map<String, ParkingTicket> activeTickets; // licensePlate → ticket

    public ParkingLot(List<ParkingLevel> levels) {
        this.levels        = levels;
        this.activeTickets = new HashMap<>();
    }

    /**
     * Searches levels in order (level 1 first = closest to exit).
     * Issues a ticket on success; throws if no spot available.
     */
    public ParkingTicket park(Vehicle vehicle) {
        for (ParkingLevel level : levels) {
            Optional<ParkingSpot> availableSpot = level.findAvailableSpot(vehicle);
            if (availableSpot.isPresent()) {
                ParkingSpot spot = availableSpot.get();
                spot.park(vehicle);
                ParkingTicket ticket = new ParkingTicket(vehicle, spot, Instant.now());
                activeTickets.put(vehicle.getLicensePlate(), ticket);
                return ticket;
            }
        }
        throw new ParkingFullException("No available spot for vehicle type: " + vehicle.getType());
    }

    /**
     * Vacates the spot, removes ticket, returns the fee to collect.
     */
    public BigDecimal exit(String licensePlate) {
        ParkingTicket ticket = activeTickets.remove(licensePlate);
        if (ticket == null) {
            throw new IllegalArgumentException("No active ticket for: " + licensePlate);
        }
        ticket.getSpot().vacate();
        return FeeCalculator.calculate(ticket, Instant.now());
    }

    public boolean isFull() {
        return levels.stream().allMatch(ParkingLevel::isFull);
    }
}
Key OOD decisions to explain in interview:
  • Vehicle is abstract (not an interface) because it holds shared state: licensePlate and type. Interfaces cannot hold instance variables.
  • canFitInSpot() lives on Vehicle (not on ParkingSpot) so spot logic never needs to know about every vehicle type — Open/Closed principle.
  • FeeCalculator is a separate class — Single Responsibility. ParkingLot does not calculate fees.

OOD Problem 2: Elevator System

Requirements: N elevators, M floors. External requests: floor + direction (UP/DOWN). Internal requests: destination floor. Dispatching algorithm: SCAN — elevator sweeps up through pending stops, then sweeps down. Optimize for minimal wait time.

// ── Enums ─────────────────────────────────────────────────────────
public enum ElevatorState { IDLE, MOVING_UP, MOVING_DOWN }
public enum Direction      { UP, DOWN }

// ── Request.java (external call from a floor) ─────────────────────
public class ExternalRequest {
    private final int floor;
    private final Direction direction;

    public ExternalRequest(int floor, Direction direction) {
        this.floor     = floor;
        this.direction = direction;
    }

    public int getFloor()           { return floor; }
    public Direction getDirection() { return direction; }
}

// ── Elevator.java ─────────────────────────────────────────────────
public class Elevator {
    private final int elevatorId;
    private int currentFloor;
    private ElevatorState state;

    /**
     * TreeSet maintains stops in ascending sorted order.
     * This enables the SCAN algorithm to sweep upward by calling
     * first() and last() — no manual sorting needed per step.
     */
    private final TreeSet<Integer> pendingStops;

    public Elevator(int elevatorId, int initialFloor) {
        this.elevatorId   = elevatorId;
        this.currentFloor = initialFloor;
        this.state        = ElevatorState.IDLE;
        this.pendingStops = new TreeSet<>();
    }

    /** Add an internal (passenger-selected) destination. */
    public void addStop(int floor) {
        pendingStops.add(floor);
        updateState();
    }

    /**
     * SCAN algorithm: process the next stop based on current direction.
     * - MOVING_UP:  take the lowest stop above currentFloor
     * - MOVING_DOWN: take the highest stop below currentFloor
     * - IDLE:       take the nearest stop
     */
    public void processNextStop() {
        if (pendingStops.isEmpty()) {
            state = ElevatorState.IDLE;
            return;
        }
        int nextFloor = resolveNextFloor();
        System.out.printf("[Elevator %d] Moving %s → Floor %d%n",
            elevatorId, state, nextFloor);
        currentFloor = nextFloor;
        pendingStops.remove(nextFloor);
        updateState();
    }

    private int resolveNextFloor() {
        Integer above = pendingStops.ceiling(currentFloor + 1);
        Integer below = pendingStops.floor(currentFloor - 1);

        if (state == ElevatorState.MOVING_UP) {
            return above != null ? above : below; // reverse if no more above
        }
        if (state == ElevatorState.MOVING_DOWN) {
            return below != null ? below : above; // reverse if no more below
        }
        // IDLE: pick nearest
        if (above == null) return below;
        if (below == null) return above;
        return (above - currentFloor) <= (currentFloor - below) ? above : below;
    }

    private void updateState() {
        if (pendingStops.isEmpty()) {
            state = ElevatorState.IDLE;
        } else if (pendingStops.last() > currentFloor) {
            state = ElevatorState.MOVING_UP;
        } else {
            state = ElevatorState.MOVING_DOWN;
        }
    }

    public int getCurrentFloor()  { return currentFloor; }
    public ElevatorState getState() { return state; }
    public int getElevatorId()    { return elevatorId; }
}

// ── ElevatorController.java ───────────────────────────────────────
public class ElevatorController {
    private final List<Elevator> elevators;

    public ElevatorController(List<Elevator> elevators) {
        this.elevators = elevators;
    }

    /**
     * Dispatches an external floor request to the best elevator:
     * 1. Idle elevator nearest to the requested floor.
     * 2. Moving elevator heading in the same direction that will pass the floor.
     * 3. Any idle elevator as fallback.
     */
    public void handleExternalRequest(ExternalRequest request) {
        Elevator bestElevator = findBestElevator(request);
        bestElevator.addStop(request.getFloor());
        System.out.printf("[Controller] Dispatched floor %d (%s) to elevator %d%n",
            request.getFloor(), request.getDirection(), bestElevator.getElevatorId());
    }

    private Elevator findBestElevator(ExternalRequest request) {
        return elevators.stream()
            .filter(e -> e.getState() == ElevatorState.IDLE)
            .min(Comparator.comparingInt(e ->
                Math.abs(e.getCurrentFloor() - request.getFloor())))
            .orElseGet(() -> elevators.stream()
                .filter(e -> isEnRoute(e, request))
                .findFirst()
                .orElse(elevators.get(0))); // fallback: first elevator
    }

    private boolean isEnRoute(Elevator elevator, ExternalRequest request) {
        boolean movingUp   = elevator.getState() == ElevatorState.MOVING_UP
            && request.getDirection() == Direction.UP
            && elevator.getCurrentFloor() < request.getFloor();
        boolean movingDown = elevator.getState() == ElevatorState.MOVING_DOWN
            && request.getDirection() == Direction.DOWN
            && elevator.getCurrentFloor() > request.getFloor();
        return movingUp || movingDown;
    }
}

OOD Problem 3: Vending Machine (State Pattern)

Requirements: Accepts coins (quarter=25¢, dime=10¢, nickel=5¢), tracks balance, displays inventory (item code → Item), dispenses if balance ≥ price and item in stock, returns optimal change. Uses the State pattern — each state (IDLE, HAS_MONEY, DISPENSING) is its own class.

// ── Coin.java ─────────────────────────────────────────────────────
public enum Coin {
    NICKEL(5), DIME(10), QUARTER(25);

    private final int valueInCents;
    Coin(int valueInCents) { this.valueInCents = valueInCents; }
    public int getValue()  { return valueInCents; }
}

// ── Item.java ─────────────────────────────────────────────────────
public class Item {
    private final String name;
    private final int priceInCents;
    private int quantity;

    public Item(String name, int priceInCents, int quantity) {
        this.name         = name;
        this.priceInCents = priceInCents;
        this.quantity     = quantity;
    }

    public boolean isAvailable()  { return quantity > 0; }
    public void decrementStock()  { quantity--; }
    public int getPrice()         { return priceInCents; }
    public String getName()       { return name; }
    public int getQuantity()      { return quantity; }
}

// ── VendingMachineState.java (interface) ──────────────────────────
public interface VendingMachineState {
    void insertCoin(VendingMachine machine, Coin coin);
    void selectItem(VendingMachine machine, String itemCode);
    void dispense(VendingMachine machine);
    void returnChange(VendingMachine machine);
}

// ── IdleState.java ────────────────────────────────────────────────
public class IdleState implements VendingMachineState {
    @Override
    public void insertCoin(VendingMachine machine, Coin coin) {
        machine.addBalance(coin.getValue());
        System.out.println("Coin inserted: " + coin + " (balance: " + machine.getBalance() + "¢)");
        machine.setState(machine.getHasMoneyState());
    }

    @Override
    public void selectItem(VendingMachine machine, String itemCode) {
        System.out.println("Please insert coins before selecting an item.");
    }

    @Override
    public void dispense(VendingMachine machine) {
        System.out.println("No item selected.");
    }

    @Override
    public void returnChange(VendingMachine machine) {
        System.out.println("No balance to return.");
    }
}

// ── HasMoneyState.java ────────────────────────────────────────────
public class HasMoneyState implements VendingMachineState {
    @Override
    public void insertCoin(VendingMachine machine, Coin coin) {
        machine.addBalance(coin.getValue());
        System.out.println("Coin inserted. Total balance: " + machine.getBalance() + "¢");
    }

    @Override
    public void selectItem(VendingMachine machine, String itemCode) {
        Item item = machine.getItem(itemCode);
        if (item == null) {
            System.out.println("Invalid item code: " + itemCode);
            return;
        }
        if (!item.isAvailable()) {
            System.out.println("Item out of stock: " + item.getName());
            return;
        }
        if (machine.getBalance() < item.getPrice()) {
            System.out.println("Insufficient balance. Need " + item.getPrice()
                + "¢, have " + machine.getBalance() + "¢");
            return;
        }
        machine.setSelectedItemCode(itemCode);
        machine.setState(machine.getDispensingState());
        machine.dispense();
    }

    @Override
    public void dispense(VendingMachine machine) {
        System.out.println("Please select an item first.");
    }

    @Override
    public void returnChange(VendingMachine machine) {
        int change = machine.getBalance();
        machine.resetBalance();
        machine.setState(machine.getIdleState());
        System.out.println("Returned " + change + "¢ in change.");
        printOptimalChange(change);
    }

    /** Greedy coin selection: quarters → dimes → nickels. */
    private void printOptimalChange(int changeInCents) {
        int remaining = changeInCents;
        int quarters  = remaining / 25; remaining %= 25;
        int dimes     = remaining / 10; remaining %= 10;
        int nickels   = remaining / 5;
        System.out.printf("Change: %d quarter(s), %d dime(s), %d nickel(s)%n",
            quarters, dimes, nickels);
    }
}

// ── DispensingState.java ──────────────────────────────────────────
public class DispensingState implements VendingMachineState {
    @Override
    public void insertCoin(VendingMachine machine, Coin coin) {
        System.out.println("Please wait — dispensing in progress.");
    }

    @Override
    public void selectItem(VendingMachine machine, String itemCode) {
        System.out.println("Already dispensing. Please wait.");
    }

    @Override
    public void dispense(VendingMachine machine) {
        Item item = machine.getItem(machine.getSelectedItemCode());
        item.decrementStock();
        machine.deductBalance(item.getPrice());
        System.out.println("Dispensing: " + item.getName());
        if (machine.getBalance() > 0) {
            machine.returnChange();
        } else {
            machine.resetBalance();
            machine.setState(machine.getIdleState());
        }
    }

    @Override
    public void returnChange(VendingMachine machine) {
        // handled automatically inside dispense()
    }
}

// ── VendingMachine.java (context) ────────────────────────────────
public class VendingMachine {
    private final Map<String, Item> inventory;
    private int balanceInCents;
    private String selectedItemCode;

    // State instances created once — no new object per transition
    private final VendingMachineState idleState       = new IdleState();
    private final VendingMachineState hasMoneyState    = new HasMoneyState();
    private final VendingMachineState dispensingState  = new DispensingState();
    private VendingMachineState currentState           = idleState;

    public VendingMachine(Map<String, Item> inventory) {
        this.inventory = inventory;
    }

    // Delegate to current state
    public void insertCoin(Coin coin)      { currentState.insertCoin(this, coin); }
    public void selectItem(String code)    { currentState.selectItem(this, code); }
    public void dispense()                 { currentState.dispense(this); }
    public void returnChange()             { currentState.returnChange(this); }

    // State accessors for state classes
    public void setState(VendingMachineState state) { this.currentState = state; }
    public VendingMachineState getIdleState()        { return idleState; }
    public VendingMachineState getHasMoneyState()    { return hasMoneyState; }
    public VendingMachineState getDispensingState()  { return dispensingState; }

    public void addBalance(int cents)    { balanceInCents += cents; }
    public void deductBalance(int cents) { balanceInCents -= cents; }
    public void resetBalance()           { balanceInCents = 0; }
    public int getBalance()              { return balanceInCents; }
    public Item getItem(String code)     { return inventory.get(code); }
    public void setSelectedItemCode(String code) { selectedItemCode = code; }
    public String getSelectedItemCode()  { return selectedItemCode; }
}

OOD Problem 4: Chess Game

Requirements: 8×8 board, 6 piece types, valid move generation per piece, check/checkmate detection, alternating turns.

// ── Color.java ────────────────────────────────────────────────────
public enum Color { WHITE, BLACK }

// ── Position.java (Java 16+ record) ──────────────────────────────
public record Position(int row, int col) {
    public boolean isWithinBoard() {
        return row >= 0 && row < 8 && col >= 0 && col < 8;
    }
}

// ── Piece.java (abstract) ─────────────────────────────────────────
public abstract class Piece {
    private final Color color;
    private Position position;

    public Piece(Color color, Position position) {
        this.color    = color;
        this.position = position;
    }

    /**
     * Returns all positions this piece can legally move to,
     * given the current board state. Does not account for leaving
     * the king in check — that validation happens in Board.
     *
     * @param board current board state for piece lookup
     * @returns list of valid destination positions
     */
    public abstract List<Position> getValidMoves(Board board);

    public Color getColor()              { return color; }
    public Position getPosition()        { return position; }
    public void setPosition(Position pos) { this.position = pos; }

    protected boolean isOpponent(Piece other) {
        return other != null && other.getColor() != this.color;
    }
}

// ── Rook.java ─────────────────────────────────────────────────────
public class Rook extends Piece {
    public Rook(Color color, Position position) { super(color, position); }

    @Override
    public List<Position> getValidMoves(Board board) {
        List<Position> validMoves = new ArrayList<>();
        int[][] directions = {{0,1},{0,-1},{1,0},{-1,0}}; // right,left,down,up

        for (int[] direction : directions) {
            int row = getPosition().row() + direction[0];
            int col = getPosition().col() + direction[1];
            while (new Position(row, col).isWithinBoard()) {
                Position candidate = new Position(row, col);
                Piece occupant = board.getPieceAt(candidate);
                if (occupant == null) {
                    validMoves.add(candidate); // empty square: can move here
                } else if (isOpponent(occupant)) {
                    validMoves.add(candidate); // capture opponent: can move, then stop
                    break;
                } else {
                    break; // blocked by own piece
                }
                row += direction[0];
                col += direction[1];
            }
        }
        return validMoves;
    }
}

// ── Knight.java ───────────────────────────────────────────────────
public class Knight extends Piece {
    private static final int[][] KNIGHT_OFFSETS = {
        {-2,-1},{-2,1},{-1,-2},{-1,2},{1,-2},{1,2},{2,-1},{2,1}
    };

    public Knight(Color color, Position position) { super(color, position); }

    @Override
    public List<Position> getValidMoves(Board board) {
        List<Position> validMoves = new ArrayList<>();
        for (int[] offset : KNIGHT_OFFSETS) {
            Position candidate = new Position(
                getPosition().row() + offset[0],
                getPosition().col() + offset[1]
            );
            if (!candidate.isWithinBoard()) continue;
            Piece occupant = board.getPieceAt(candidate);
            if (occupant == null || isOpponent(occupant)) {
                validMoves.add(candidate);
            }
        }
        return validMoves;
    }
}

// ── Board.java ────────────────────────────────────────────────────
public class Board {
    private final Piece[][] grid = new Piece[8][8];

    public Piece getPieceAt(Position position) {
        return grid[position.row()][position.col()];
    }

    public void setPieceAt(Position position, Piece piece) {
        grid[position.row()][position.col()] = piece;
    }

    /**
     * Moves a piece from 'from' to 'to'. Validates that the destination
     * is in the piece's valid move list before executing.
     *
     * @throws IllegalArgumentException if the move is invalid
     */
    public void movePiece(Position from, Position to) {
        Piece piece = getPieceAt(from);
        if (piece == null) throw new IllegalArgumentException("No piece at " + from);

        List<Position> validMoves = piece.getValidMoves(this);
        if (!validMoves.contains(to)) {
            throw new IllegalArgumentException("Invalid move for " + piece.getClass().getSimpleName());
        }
        setPieceAt(to, piece);
        setPieceAt(from, null);
        piece.setPosition(to);
    }

    /**
     * Checks whether the king of the given color is currently in check.
     * Iterates all opponent pieces and checks if any can reach the king's position.
     */
    public boolean isInCheck(Color color) {
        Position kingPosition = findKingPosition(color);
        Color opponentColor   = (color == Color.WHITE) ? Color.BLACK : Color.WHITE;

        return getAllPiecesOfColor(opponentColor).stream()
            .anyMatch(piece -> piece.getValidMoves(this).contains(kingPosition));
    }

    private Position findKingPosition(Color color) {
        for (int row = 0; row < 8; row++) {
            for (int col = 0; col < 8; col++) {
                Piece piece = grid[row][col];
                if (piece instanceof King && piece.getColor() == color) {
                    return new Position(row, col);
                }
            }
        }
        throw new IllegalStateException("King not found for color: " + color);
    }

    private List<Piece> getAllPiecesOfColor(Color color) {
        List<Piece> pieces = new ArrayList<>();
        for (Piece[] row : grid) {
            for (Piece piece : row) {
                if (piece != null && piece.getColor() == color) {
                    pieces.add(piece);
                }
            }
        }
        return pieces;
    }
}

// ── Game.java ─────────────────────────────────────────────────────
public class Game {
    private final Board board;
    private Color currentTurn;

    public Game() {
        this.board       = new Board();
        this.currentTurn = Color.WHITE;
        initializeBoard();
    }

    public void makeMove(Position from, Position to) {
        Piece piece = board.getPieceAt(from);
        if (piece == null || piece.getColor() != currentTurn) {
            throw new IllegalArgumentException("Not your piece or empty square.");
        }
        board.movePiece(from, to);

        if (board.isInCheck(currentTurn)) {
            // Undo the move — left own king in check
            board.movePiece(to, from); // simplified: does not restore captured piece
            throw new IllegalArgumentException("Move leaves your king in check.");
        }
        currentTurn = (currentTurn == Color.WHITE) ? Color.BLACK : Color.WHITE;
    }

    private void initializeBoard() {
        // Place all pieces in starting positions (abbreviated for clarity)
        board.setPieceAt(new Position(0, 0), new Rook(Color.WHITE, new Position(0, 0)));
        board.setPieceAt(new Position(0, 1), new Knight(Color.WHITE, new Position(0, 1)));
        // ... (all 32 pieces placed similarly)
    }
}
