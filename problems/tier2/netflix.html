Tier 2 — Should Know 45 min Video streaming

Design Netflix

Netflix's core technical challenge is delivering high-quality video to 200M users across wildly different network conditions. Adaptive Bitrate Streaming (ABR) is the key — the client constantly measures bandwidth and switches quality seamlessly.

🏢 Netflix, YouTube, Amazon
⏱️ 45 min interview
🎬 15% of internet traffic

❓R — Requirements3–5 min

Functional Requirements

  • Upload and stream video content (movies, TV shows)
  • Adaptive quality streaming — auto-adjust to network conditions
  • Resume watching from last position across devices
  • Browse catalog, search titles, personalized recommendations
  • Multiple user profiles per account

Non-Functional Requirements

  • Scale: 200M subscribers, 200M streaming hours/day
  • Latency: Video starts in <2s (buffering before first frame)
  • Availability: 99.99% — buffering is revenue loss
  • Bandwidth: Netflix uses ~15% of global internet traffic at peak

🔢E — Estimation3–5 min

  • 200M hours/day streaming; avg 1.5 hrs/session → ~133M concurrent sessions at peak
  • 1080p stream = ~5 Mbps; 133M streams × 5 Mbps = 665 Tbps of egress bandwidth
  • Transcoding: 1 hr of 4K source → encode to 10 quality levels × 2 codecs (H.264, HEVC) → 20 files, each ~5–50GB. Total library ~10 PB.
  • CDN servers worldwide; Netflix places Open Connect Appliances (OCA) in ISP data centers to serve 95% of traffic locally.

🗄️S — Schema3–5 min

// Content catalog (PostgreSQL / DynamoDB)
titles: title_id, name, description, release_year, genre[], rating, duration_seconds
title_media: title_id, quality_tier (240p/480p/720p/1080p/4K), codec, s3_key, bitrate_kbps

// User watch history (Cassandra — per-user time series)
// partition: user_id, clustering: watched_at DESC
watch_history: (user_id, title_id, profile_id, watched_at, position_seconds, completed)

// User resume position (Redis — low latency, frequent updates)
// Key: resume:{user_id}:{title_id}  Value: {position_seconds, updated_at}

// Manifest per title (generated at transcoding time, cached on CDN)
// m3u8 playlist: references all quality tiers and segment URLs

🏗️H — High-level Design10 min

  • Content upload: Studio uploads raw 4K source → S3 → Transcoding Service (distributed encoding cluster) → multiple quality tiers → stored in S3 → pushed to Open Connect CDN nodes.
  • Streaming flow: Client → API → Manifest Service (returns .m3u8 playlist URL) → Client fetches manifest from CDN → Client downloads 2–4 second segments from CDN based on ABR algorithm.
  • Open Connect (OCA): Netflix's private CDN. Servers placed inside ISP facilities worldwide. ISP benefits from reduced peering cost; Netflix benefits from speed. Proactively pre-positions popular content overnight.
  • Recommendation Service: Offline training on watch history → user/item embeddings. Online: ANN lookup for similar titles → re-rank by recency, diversity, A/B test bucket.
  • Resume Service: Client posts position update every 60s to Redis. On app open, fetch position → seek to byte offset in video stream.

🔌A — APIs5 min

GET  /v1/titles/{titleId}/manifest    // returns CDN URL of .m3u8 playlist
GET  /v1/recommendations?profileId={id}&limit=20
POST /v1/watch-history                // { titleId, profileId, positionSeconds }
GET  /v1/resume/{titleId}?profileId={id}   // returns { positionSeconds }
GET  /v1/search?q={query}&genre={}&limit=20

🔬D — Deep Dive: Adaptive Bitrate Streaming (ABR)10 min

ABR is how Netflix delivers smooth video on everything from a 4G phone to a 10 Gbps fiber connection.

  1. Manifest (.m3u8): An HLS playlist listing available quality tiers with their segment URLs. The client downloads this first.
  2. Segments: Each tier is cut into 2–4 second MPEG-TS or fMP4 segments. Segments are independently decodable.
  3. Buffer level: Client maintains a playback buffer (target: 30 seconds ahead). Buffer level drives quality decisions.
  4. Bandwidth estimation: Client measures download speed of the last N segments (EWMA). If estimated bandwidth > next tier bitrate, step up. If buffer < 10s, step down.
  5. VMAF (Video Multi-method Assessment Fusion): Netflix's perceptual quality metric. Used during encoding to optimize quality-per-bitrate, not just PSNR.

Why ABR beats fixed quality: A 1080p stream at 8 Mbps on a 3 Mbps connection causes buffering. ABR automatically drops to 720p at 2.5 Mbps — the user keeps watching without interruption.

✅E — Evaluate3 min

  • Transcoding cost: A 2-hour 4K movie generates ~200GB of encoded files. Netflix encodes per-title at optimal bitrate ladders using VMAF, not a fixed ladder — this reduces storage ~40%.
  • CDN cache misses: Long-tail titles (rare requests) miss the OCA cache and hit S3. Acceptable since rare titles have fewer concurrent viewers.
  • DRM: Widevine/FairPlay/PlayReady. Segments are encrypted; client fetches license key from DRM server before decryption. Key not shown in design because it's a legal/integration concern, not a systems problem.

🚀D — Deliver2 min

We designed Netflix handling 200M users and 665 Tbps of egress. Key decisions: HLS + ABR for adaptive quality, Open Connect CDN inside ISPs for 95% of traffic, distributed transcoding pipeline producing 10+ quality tiers per title, and Redis for sub-100ms resume position lookups.

☕Java Implementation

/**
 * ABRController — selects the optimal video quality tier based on
 * current bandwidth estimate and playback buffer level.
 * Runs client-side; included here to illustrate the algorithm.
 */
public class ABRController {

    // Quality tiers: name → required bandwidth in kbps
    private static final List<QualityTier> QUALITY_TIERS = List.of(
        new QualityTier("240p",  400),
        new QualityTier("480p",  1000),
        new QualityTier("720p",  2500),
        new QualityTier("1080p", 5000),
        new QualityTier("4K",    15000)
    );

    // Buffer thresholds in seconds
    private static final int BUFFER_PANIC_THRESHOLD_SECONDS = 10;  // drop quality immediately
    private static final int BUFFER_TARGET_SECONDS          = 30;  // ideal buffer level

    // Bandwidth estimate: exponential weighted moving average
    private static final double EWMA_ALPHA = 0.3; // weight of latest measurement
    private double estimatedBandwidthKbps = 1000; // initial conservative estimate

    private int currentTierIndex = 0; // start at lowest quality

    /**
     * Called after each segment download completes.
     * Updates bandwidth estimate and selects the tier for the next segment.
     *
     * @param downloadedBytes      size of the segment just downloaded
     * @param downloadDurationMs   time it took to download
     * @param bufferLevelSeconds   current playback buffer depth
     * @return name of quality tier to request for the next segment
     */
    public String selectNextQuality(long downloadedBytes, long downloadDurationMs, int bufferLevelSeconds) {
        updateBandwidthEstimate(downloadedBytes, downloadDurationMs);

        if (bufferLevelSeconds < BUFFER_PANIC_THRESHOLD_SECONDS) {
            // Emergency: buffer critically low — drop to lowest quality immediately
            currentTierIndex = 0;
        } else {
            currentTierIndex = findOptimalTierIndex(bufferLevelSeconds);
        }

        return QUALITY_TIERS.get(currentTierIndex).getName();
    }

    /**
     * Finds the highest quality tier whose bitrate fits within estimated bandwidth,
     * with a safety margin that tightens when the buffer is low.
     */
    private int findOptimalTierIndex(int bufferLevelSeconds) {
        // Safety margin: tighter when buffer is low (0.5×), relaxed when buffer is healthy (0.9×)
        double safetyMargin = (bufferLevelSeconds >= BUFFER_TARGET_SECONDS) ? 0.9 : 0.6;
        double usableBandwidthKbps = estimatedBandwidthKbps * safetyMargin;

        int bestTierIndex = 0;
        for (int tierIndex = 0; tierIndex < QUALITY_TIERS.size(); tierIndex++) {
            if (QUALITY_TIERS.get(tierIndex).getRequiredKbps() <= usableBandwidthKbps) {
                bestTierIndex = tierIndex;
            }
        }

        // Limit quality increase to one step at a time (prevents oscillation)
        return Math.min(bestTierIndex, currentTierIndex + 1);
    }

    /**
     * Updates the EWMA bandwidth estimate with the latest measurement.
     * EWMA smooths out transient spikes and drops.
     */
    private void updateBandwidthEstimate(long downloadedBytes, long downloadDurationMs) {
        if (downloadDurationMs <= 0) {
            return;
        }
        double measuredKbps = (downloadedBytes * 8.0) / downloadDurationMs; // bits/ms = kbps
        estimatedBandwidthKbps = EWMA_ALPHA * measuredKbps + (1 - EWMA_ALPHA) * estimatedBandwidthKbps;
    }

    private record QualityTier(String name, int requiredKbps) {
        public String getName() { return name; }
        public int getRequiredKbps() { return requiredKbps; }
    }
}
