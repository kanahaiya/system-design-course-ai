Tier 1 — Must Know 45 min Media Systems

Design YouTube / Video Streaming

500 hours of video uploaded per minute. The interview is really about two things: async transcoding pipelines and adaptive bitrate streaming. Nail those and you win.

🏢 Google, Netflix, Meta
⏱️ 45 min interview
📺 2B MAU

❓ R — Requirements 3–5 min

Functional Requirements

  • Upload a video (up to 10GB)
  • Stream video adaptively (quality adjusts to bandwidth)
  • Search videos by title/description
  • Like, comment, subscribe
  • View recommendations (out of scope — ML team owns this)

Non-Functional Requirements

  • Scale: 2B MAU, 500 hours uploaded per minute, 5B views/day
  • Streaming latency: Playback starts within 2 seconds
  • Availability: 99.99% for streaming (revenue-critical)
  • Durability: Videos must never be lost
  • Consistency: Upload confirmation is async — video may not be watchable for 30 seconds after upload while transcoding runs

🔢 E — Estimation 5 min

  • Upload storage: 500 hrs/min × 60 = 30,000 hrs/hr → at 1GB/hr compressed = 30TB new data/day
  • Transcoding: Each video transcoded to 5 resolutions → 150TB/day processed
  • CDN bandwidth: 5B views × 300MB avg (30 min at 720p) = 1.5 exabytes/day — YouTube uses all major CDNs
  • Streaming QPS: 5B / 86,400 ≈ 58,000 stream-start requests/sec
  • Metadata DB: 500 hrs/min × 60 × 24 × 365 = 263M videos/year × 5KB metadata = ~1.3TB/year (trivial)
The bottleneck is not metadata — it's CDN bandwidth and transcoding throughput. Design decisions should reflect this.

🏗️ H — High-level Design 10 min

Figure: YouTube upload pipeline (top) — Creator → Transcoding Farm → S3 → CDN; Playback pipeline (bottom) — Viewer → CDN Edge → ABR Player

Upload Path

  1. Client requests an upload URL from Upload Service
  2. Upload Service returns a pre-signed S3 URL — client uploads directly to S3 (bypasses app servers)
  3. S3 triggers a Kafka event (ObjectCreated) → Transcoding Service picks it up
  4. Transcoding Service spawns workers to convert to 360p/480p/720p/1080p/4K — each resolution is a separate job
  5. Chunked output (.ts files + .m3u8 manifest) written to S3; metadata updated to READY

Stream Path

  1. Client requests /watch?v={videoId} → Video Service returns metadata + CDN URL of master manifest
  2. Client fetches master.m3u8 from CDN → receives list of resolution-specific playlists
  3. Client selects resolution based on current bandwidth → fetches 2–10 second chunks from CDN
  4. On CDN miss: CDN pulls chunk from S3 origin and caches it
Key insight: Never stream directly from S3 to clients. CDN edge servers handle 99% of streaming traffic. S3 is origin-of-record, not a streaming server.

🔬 D — Deep Dive: Video Transcoding Pipeline 10 min

Transcoding is CPU-intensive and takes minutes per video. It must be asynchronous and resilient to node failures.

Adaptive Bitrate (ABR) with HLS

  • Input: raw MP4. Output: multiple resolution streams, each split into 2-second .ts chunks.
  • master.m3u8: index pointing to per-resolution playlists
  • Client player selects quality automatically based on available bandwidth
  • Switching quality = fetching next chunk from a different resolution playlist — seamless

Job State Machine

Each upload triggers a job with states: QUEUED → TRANSCODING → UPLOADING_CHUNKS → DONE / FAILED. Failed jobs are retried up to 3 times with exponential backoff. If permanently failed, mark video status as FAILED and notify uploader.

⚖️ E — Evaluate 5 min

  • Transcoding worker crash: Job remains in Kafka, another worker picks it up. Idempotent — re-transcoding overwrites same S3 paths.
  • CDN outage in one region: GeoDNS reroutes to nearest available CDN PoP. Higher latency but service stays up.
  • Hot video (viral): CDN handles 99%+ of traffic. Origin S3 only serves cache misses. S3 is effectively infinite-scale object storage.
  • Storage cost: Move videos not viewed in 90 days to S3 Glacier (10× cheaper). Manifest/chunk pointers remain; streaming triggers a restore job.

🚀 D — Deliver 2 min

"Videos are uploaded directly to S3 via pre-signed URLs, then transcoded asynchronously via a Kafka-driven worker pipeline into HLS chunks at multiple resolutions. Streaming uses CDN edge delivery — the client fetches a manifest and adaptively switches quality based on bandwidth. S3 is origin storage; CDN handles all streaming load. The design is resilient: transcoding failures are retried via Kafka, and CDN provides geographic redundancy."

⚖️ Key Trade-offs

DecisionOption AOption BWinner
Upload Target Client → App Server → S3 Client → S3 direct (pre-signed URL) Direct S3 — avoids double transfer, removes app server bottleneck
CDN Strategy Push CDN (pre-load all videos) Pull CDN (cache on first request) Pull CDN — 500M videos; push would be cost-prohibitive
Streaming Protocol HLS (HTTP Live Streaming) DASH (Dynamic Adaptive Streaming) HLS — native iOS support; DASH for Android/web (support both in practice)
Transcoding Synchronous (user waits) Asynchronous (Kafka + workers) Async — 1080p transcoding takes minutes; blocking upload is unacceptable

☕ Java Implementation 

/**
 * TranscodingJob — represents a single video transcoding task with state machine.
 */
public class TranscodingJob {
    public enum Status { QUEUED, TRANSCODING, UPLOADING_CHUNKS, DONE, FAILED }

    private final String jobId;
    private final long videoId;
    private final String rawS3Path;
    private volatile Status status;
    private int retryCount;
    private static final int MAX_RETRIES = 3;

    public TranscodingJob(String jobId, long videoId, String rawS3Path) {
        this.jobId = jobId;
        this.videoId = videoId;
        this.rawS3Path = rawS3Path;
        this.status = Status.QUEUED;
        this.retryCount = 0;
    }

    public boolean canRetry() {
        return retryCount < MAX_RETRIES;
    }

    public void incrementRetry() { retryCount++; }

    // Getters
    public String getJobId() { return jobId; }
    public long getVideoId() { return videoId; }
    public String getRawS3Path() { return rawS3Path; }
    public Status getStatus() { return status; }
    public void setStatus(Status status) { this.status = status; }
}

/**
 * VideoTranscodingPipeline — Kafka consumer that orchestrates transcoding.
 * Each video is transcoded to multiple resolutions in parallel.
 */
public class VideoTranscodingPipeline {
    private static final List TARGET_RESOLUTIONS =
            List.of("360p", "480p", "720p", "1080p", "4k");
    private static final int CHUNK_DURATION_SECONDS = 2;
    private static final String CHUNKS_S3_PREFIX = "chunks/";
    private static final String MANIFESTS_S3_PREFIX = "manifests/";

    private final FFmpegTranscoder ffmpegTranscoder;
    private final S3Client s3Client;
    private final VideoRepository videoRepository;
    private final TranscodingJobRepository jobRepository;

    public VideoTranscodingPipeline(FFmpegTranscoder ffmpegTranscoder,
                                    S3Client s3Client,
                                    VideoRepository videoRepository,
                                    TranscodingJobRepository jobRepository) {
        this.ffmpegTranscoder = ffmpegTranscoder;
        this.s3Client = s3Client;
        this.videoRepository = videoRepository;
        this.jobRepository = jobRepository;
    }

    /**
     * Entry point called by Kafka consumer thread.
     * Processes one video upload event.
     *
     * @param event Kafka event from S3 ObjectCreated notification
     */
    public void processUploadEvent(VideoUploadedEvent event) {
        TranscodingJob job = new TranscodingJob(
                UUID.randomUUID().toString(), event.getVideoId(), event.getRawS3Path());
        jobRepository.save(job);

        try {
            transcodeAllResolutions(job);
            generateMasterManifest(job.getVideoId());
            videoRepository.updateStatus(job.getVideoId(), VideoStatus.READY);
            job.setStatus(TranscodingJob.Status.DONE);
            jobRepository.save(job);
        } catch (TranscodingException transcodingException) {
            handleTranscodingFailure(job, transcodingException);
        }
    }

    /**
     * Transcodes a video to all target resolutions in parallel using a thread pool.
     * Each resolution produces a set of .ts chunks and a resolution-specific .m3u8 playlist.
     */
    private void transcodeAllResolutions(TranscodingJob job) throws TranscodingException {
        job.setStatus(TranscodingJob.Status.TRANSCODING);
        jobRepository.save(job);

        ExecutorService transcodingExecutor = Executors.newFixedThreadPool(TARGET_RESOLUTIONS.size());
        List> transcodingFutures = new ArrayList<>();

        for (String resolution : TARGET_RESOLUTIONS) {
            Future future = transcodingExecutor.submit(
                    () -> transcodeToResolution(job, resolution));
            transcodingFutures.add(future);
        }

        List resolutionResults = new ArrayList<>();
        for (Future future : transcodingFutures) {
            try {
                resolutionResults.add(future.get(30, TimeUnit.MINUTES));
            } catch (TimeoutException | ExecutionException | InterruptedException exception) {
                throw new TranscodingException("Resolution transcoding failed", exception);
            }
        }

        transcodingExecutor.shutdown();
        uploadChunksToS3(job, resolutionResults);
    }

    private ResolutionResult transcodeToResolution(TranscodingJob job, String resolution) {
        // Download raw file from S3 to local temp dir
        Path rawLocalPath = s3Client.downloadToTemp(job.getRawS3Path());

        // Run FFmpeg to produce .ts chunks
        List chunkPaths = ffmpegTranscoder.transcodeToHlsChunks(
                rawLocalPath, resolution, CHUNK_DURATION_SECONDS);

        // Generate per-resolution .m3u8 playlist
        String resolutionPlaylistContent = buildResolutionPlaylist(job.getVideoId(), resolution, chunkPaths);

        return new ResolutionResult(resolution, chunkPaths, resolutionPlaylistContent);
    }

    private void uploadChunksToS3(TranscodingJob job, List resolutionResults) {
        job.setStatus(TranscodingJob.Status.UPLOADING_CHUNKS);
        jobRepository.save(job);

        for (ResolutionResult result : resolutionResults) {
            for (int chunkIndex = 0; chunkIndex < result.getChunkPaths().size(); chunkIndex++) {
                String s3Key = CHUNKS_S3_PREFIX + job.getVideoId()
                        + "/" + result.getResolution()
                        + "/" + chunkIndex + ".ts";
                s3Client.upload(result.getChunkPaths().get(chunkIndex), s3Key);
            }
            // Upload per-resolution playlist
            String playlistKey = CHUNKS_S3_PREFIX + job.getVideoId()
                    + "/" + result.getResolution() + "/playlist.m3u8";
            s3Client.uploadString(result.getPlaylistContent(), playlistKey);
        }
    }

    /**
     * Generates the HLS master manifest referencing all resolution playlists.
     * Example output:
     *   #EXTM3U
     *   #EXT-X-STREAM-INF:BANDWIDTH=800000,RESOLUTION=640x360
     *   chunks/{videoId}/360p/playlist.m3u8
     */
    private void generateMasterManifest(long videoId) {
        StringBuilder masterManifest = new StringBuilder("#EXTM3U\n");
        Map resolutionBandwidthMap = Map.of(
                "360p", 800_000, "480p", 1_500_000,
                "720p", 3_000_000, "1080p", 5_000_000, "4k", 15_000_000);

        for (String resolution : TARGET_RESOLUTIONS) {
            int bandwidth = resolutionBandwidthMap.get(resolution);
            masterManifest.append("#EXT-X-STREAM-INF:BANDWIDTH=").append(bandwidth)
                          .append(",RESOLUTION=").append(resolutionToWidthHeight(resolution)).append("\n");
            masterManifest.append(CHUNKS_S3_PREFIX).append(videoId)
                          .append("/").append(resolution).append("/playlist.m3u8\n");
        }

        String masterKey = MANIFESTS_S3_PREFIX + videoId + "/master.m3u8";
        s3Client.uploadString(masterManifest.toString(), masterKey);
    }

    private String buildResolutionPlaylist(long videoId, String resolution, List chunks) {
        StringBuilder playlist = new StringBuilder("#EXTM3U\n#EXT-X-VERSION:3\n");
        playlist.append("#EXT-X-TARGETDURATION:").append(CHUNK_DURATION_SECONDS).append("\n");
        for (int index = 0; index < chunks.size(); index++) {
            playlist.append("#EXTINF:").append(CHUNK_DURATION_SECONDS).append(",\n");
            playlist.append(CHUNKS_S3_PREFIX).append(videoId).append("/")
                    .append(resolution).append("/").append(index).append(".ts\n");
        }
        playlist.append("#EXT-X-ENDLIST\n");
        return playlist.toString();
    }

    private void handleTranscodingFailure(TranscodingJob job, TranscodingException exception) {
        if (job.canRetry()) {
            job.incrementRetry();
            job.setStatus(TranscodingJob.Status.QUEUED);
            jobRepository.save(job);
            // Re-enqueue to Kafka with exponential backoff delay
            long backoffMs = (long) Math.pow(2, job.getRetryCount()) * 1000L;
            scheduleRetry(job, backoffMs);
        } else {
            job.setStatus(TranscodingJob.Status.FAILED);
            jobRepository.save(job);
            videoRepository.updateStatus(job.getVideoId(), VideoStatus.FAILED);
        }
    }

    private void scheduleRetry(TranscodingJob job, long delayMs) {
        // In production: send to a Kafka delayed-retry topic
        // Simplified: use ScheduledExecutorService
        ScheduledExecutorService scheduler = Executors.newSingleThreadScheduledExecutor();
        scheduler.schedule(() -> processUploadEvent(
                new VideoUploadedEvent(job.getVideoId(), job.getRawS3Path())),
                delayMs, TimeUnit.MILLISECONDS);
    }

    private String resolutionToWidthHeight(String resolution) {
        return switch (resolution) {
            case "360p" -> "640x360";
            case "480p" -> "854x480";
            case "720p" -> "1280x720";
            case "1080p" -> "1920x1080";
            case "4k" -> "3840x2160";
            default -> throw new IllegalArgumentException("Unknown resolution: " + resolution);
        };
    }
}
