Tier 1 — Must Know 45 min

Design a Web Crawler

Design a distributed web crawler that crawls 1 billion pages per day, deduplicates URLs and content at scale using Bloom filters and SimHash, while respecting politeness rules and robots.txt.

🏢 Google, Bing, Common Crawl, Amazon
⏱️ 45 min

R — Requirements

Functional Requirements

  • Start from a set of seed URLs and crawl the web via discovered links
  • Extract and store page content (HTML) to object storage
  • Discover new URLs from crawled pages and add to the frontier
  • Respect robots.txt and crawl-delay directives per domain
  • Avoid re-crawling duplicate or near-duplicate content

Non-Functional Requirements

  • Scale: 1B pages/day, 10B total URLs in the frontier
  • Throughput: 11,574 pages/second sustained
  • Politeness: no more than 1 request/second per domain
  • Storage: ~10TB/day fetched, ~1TB/day after deduplication
  • Freshness: popular pages re-crawled every hour, others weekly
The hardest problems: deduplication at 10B URL scale and politeness at 11K pages/sec across millions of domains. These two are what interviewers care about most.

    url_hash     TEXT PRIMARY KEY,
    content_hash TEXT,          -- SHA-256 of content for exact dedup
    simhash      BIGINT,        -- 64-bit SimHash for near-dedup
    storage_key  TEXT,          -- S3 key: crawl/{year}/{month}/{url_hash}.gz
    crawled_at   TIMESTAMP,

    content_size INT

-- Robots cache (Redis, TTL = robots.txt max-age)
-- Key: robots:{domain}
-- Value: serialized RobotsRules object with crawl-delay, disallowed paths
Why Cassandra for the frontier? The frontier needs ~10B rows with high write throughput as discovered URLs pour in. Cassandra's wide-column model with domain as partition key co-locates all URLs for a domain, enabling efficient politeness enforcement.

Figure: Web crawler BFS loop — Frontier Queue → Fetcher → Parser → Normalizer → Bloom Filter check → discard (seen) or enqueue (new)

  1. URL Frontier maintains a priority queue in Cassandra, partitioned by domain so each domain's URLs stay together
  2. Scheduler dequeues batches of URLs, checks robots.txt cache, enforces per-domain crawl-delay
  3. Fetcher Pool (~1000 distributed workers) fetches pages via HTTP. Each fetcher handles its own domain queues
  4. HTML Parser extracts all <a href> links, normalizes them (strip tracking params, lowercase, canonical form)
  5. Deduplicator checks Bloom filter: new URL → add to Bloom filter + enqueue; seen URL → discard
  6. Content Store computes SimHash of page body; if SimHash distance < threshold → near-duplicate → skip storage

D — Deep Dive: Deduplication at Scale

URL Deduplication — Bloom Filter

A Bloom filter is a probabilistic data structure using k hash functions and a bit array. To add a URL: hash it k times, set those k bits. To check: hash k times, if all bits are set → probably seen; if any bit is 0 → definitely not seen.

At 10B URLs with 1% false positive rate: bit array size = 10B × 10 bits = 10B bits = 12.5 GB. This fits in memory and is shardable. False positives (skipping a URL we haven't seen) are acceptable — we miss ~1% of URLs but save massive DB lookups.

Content Deduplication — SimHash

SimHash creates a 64-bit fingerprint where similar documents have similar fingerprints (Hamming distance ≤ 3 = near-duplicate). Algorithm: tokenize text → hash each token → sum weighted hash bits → take sign of each bit dimension.

Why not MD5/SHA for content dedup? MD5 only catches exact duplicates. Two pages with 95% identical content (different ads, timestamps) have completely different MD5 hashes. SimHash catches near-duplicates.

E — Evaluate

  • Spider trap: Site generates infinite URLs (e.g., calendar with infinite next-page links). Solution: cap URL length at 2048 chars, limit depth per domain to 20 hops, limit URLs per domain to 10M.
  • Dynamic content (JavaScript): Standard HTTP fetcher gets static HTML. Use a headless Chrome pool (Puppeteer) for JS-heavy sites flagged by a heuristic (site map or manually marked).
  • DNS poisoning / malicious redirects: Validate that redirected domain is still allowed by robots.txt. Don't follow more than 5 redirects.
  • Politeness enforcement: Each fetcher node owns a set of domains. Uses a per-domain timestamp to ensure minimum crawl-delay between requests to the same server.

D — Deliver

The architecture is a pipeline of loosely coupled services connected by message queues (Kafka). This allows independent scaling of each stage — if parsing is slow, add more parsers; if fetching is the bottleneck, add fetcher nodes.

Key insight: The system is eventually consistent by design. A URL missed today due to a Bloom filter false positive will likely be discovered again from another page tomorrow. Correctness over time matters more than per-request correctness.

Java Implementation

/**
 * BloomFilter
 * Space-efficient probabilistic data structure for URL deduplication.
 * Uses k independent hash functions over a bit array.
 * False positives possible; false negatives impossible.
 */
public class BloomFilter {

    private final BitSet bitArray;
    private final int bitArraySize;
    private final int numberOfHashFunctions;

    /**
     * Creates a Bloom filter optimized for the given capacity and false-positive rate.
     *
     * @param expectedElements   number of elements to store (e.g., 10_000_000_000L for 10B)
     * @param falsePositiveRate  acceptable false positive probability (e.g., 0.01 for 1%)
     */
    public BloomFilter(long expectedElements, double falsePositiveRate) {
        // Optimal bit array size: m = -n*ln(p) / (ln(2))^2
        this.bitArraySize = (int) Math.ceil(
            -expectedElements * Math.log(falsePositiveRate) / (Math.log(2) * Math.log(2))
        );
        // Optimal k: k = (m/n) * ln(2)
        this.numberOfHashFunctions = (int) Math.ceil(
            ((double) bitArraySize / expectedElements) * Math.log(2)
        );
        this.bitArray = new BitSet(bitArraySize);
    }

    /**
     * Adds a URL to the filter. After this call, mightContain() will return true.
     *
     * @param url the URL string to add
     */
    public void add(String url) {
        for (int hashIndex = 0; hashIndex < numberOfHashFunctions; hashIndex++) {
            int bitPosition = computeHashPosition(url, hashIndex);
            bitArray.set(bitPosition);
        }
    }

    /**
     * Tests whether a URL might be in the filter.
     * Returns true = probably seen (act as if seen).
     * Returns false = definitely not seen (safe to crawl).
     *
     * @param url the URL to test
     * @return true if probably present, false if definitely absent
     */
    public boolean mightContain(String url) {
        for (int hashIndex = 0; hashIndex < numberOfHashFunctions; hashIndex++) {
            int bitPosition = computeHashPosition(url, hashIndex);
            if (!bitArray.get(bitPosition)) {
                return false; // definite miss
            }
        }
        return true; // probable hit
    }

    /**
     * Computes the bit array position for this url + hash function index.
     * Uses double hashing: h(url, i) = hash1(url) + i * hash2(url)
     * This avoids needing k independent hash implementations.
     */
    private int computeHashPosition(String url, int hashIndex) {
        long hash1 = murmurHash64(url, 0);
        long hash2 = murmurHash64(url, hash1);
        long combinedHash = Math.abs(hash1 + (long) hashIndex * hash2);
        return (int) (combinedHash % bitArraySize);
    }

    private long murmurHash64(String input, long seed) {
        // Simplified MurmurHash3 — production should use Guava's Hashing.murmur3_128()
        long hashValue = seed ^ (input.length() * 0xc4ceb9fe1a85ec53L);
        for (char character : input.toCharArray()) {
            hashValue ^= character;
            hashValue *= 0xff51afd7ed558ccdL;
            hashValue ^= hashValue >>> 33;
        }
        return hashValue;
    }
}

/**
 * UrlNormalizer
 * Converts raw extracted URLs into a canonical form to maximize dedup hit rate.
 */
public class UrlNormalizer {

    // Query parameters that are tracking-only and should be stripped
    private static final Set<String> TRACKING_PARAMS = Set.of(
        "utm_source", "utm_medium", "utm_campaign", "utm_content", "utm_term",
        "fbclid", "gclid", "msclkid", "ref", "source"
    );

    /**
     * Normalizes a URL for deduplication purposes.
     * Strips tracking params, normalizes scheme/host to lowercase,
     * removes default ports, sorts remaining query params.
     *
     * @param rawUrl the raw URL extracted from HTML
     * @param baseUrl the page URL this was extracted from (for relative URL resolution)
     * @return normalized URL string, or empty if URL is invalid/unsupported
     */
    public Optional<String> normalize(String rawUrl, String baseUrl) {
        try {
            URI resolvedUri = URI.create(baseUrl).resolve(rawUrl.trim());
            String scheme = resolvedUri.getScheme().toLowerCase();

            if (!scheme.equals("http") && !scheme.equals("https")) {
                return Optional.empty(); // skip mailto:, ftp:, javascript:, etc.
            }

            String normalizedHost = resolvedUri.getHost().toLowerCase();
            String normalizedPath = normalizePath(resolvedUri.getPath());
            String filteredQuery = filterQueryParameters(resolvedUri.getQuery());

            String normalizedUrl = scheme + "://" + normalizedHost + normalizedPath;
            if (filteredQuery != null && !filteredQuery.isEmpty()) {
                normalizedUrl += "?" + filteredQuery;
            }

            return Optional.of(normalizedUrl);
        } catch (IllegalArgumentException invalidUrlException) {
            return Optional.empty();
        }
    }

    private String normalizePath(String path) {
        if (path == null || path.isEmpty()) {
            return "/";
        }
        // Collapse double slashes, resolve .. segments
        return path.replaceAll("//+", "/").toLowerCase();
    }

    private String filterQueryParameters(String queryString) {
        if (queryString == null) {
            return null;
        }
        return Arrays.stream(queryString.split("&"))
            .filter(param -> {
                String paramName = param.split("=")[0].toLowerCase();
                return !TRACKING_PARAMS.contains(paramName);
            })
            .sorted()
            .collect(Collectors.joining("&"));
    }
}
