Tier 1 — Must Know 45 min Algorithms-heavy

Design a Distributed Cache (like Memcached/Redis)

This problem tests one core algorithm interviewers care about deeply: consistent hashing. Naive modulo hashing remaps 100% of keys when you add a node. Consistent hashing remaps only K/N keys. Know this cold.

🏢 Amazon, Meta, Google
⏱️ 45 min interview
⚡ <1ms p99

❓ R — Requirements 3–5 min

Functional Requirements

  • put(key, value, ttl) — store value with optional TTL
  • get(key) — retrieve value, return null on miss or expired
  • delete(key) — explicitly remove a key
  • Auto-eviction when cache node is full (LRU)

Non-Functional Requirements

  • Latency: < 1ms p99 for get and put operations
  • Availability: 99.99% — cache is in the hot path of most requests
  • Scale: 10TB total cache storage, 1M QPS
  • Horizontal scaling: Adding a node should not require rehashing all existing keys

🔢 E — Estimation 5 min

  • Storage: 10TB / 1KB avg value = 10B entries
  • Node count: 10TB / 100GB RAM per node = 100 nodes
  • QPS per node: 1M / 100 = 10,000 QPS/node — well within in-memory hashtable capacity
  • Network: 1M × 1KB = 1GB/s peak bandwidth — need 10Gbps NICs
  • Consistent hash ring size: Use 150 virtual nodes per physical node → 15,000 ring points for 100 nodes — excellent key distribution

🗄️ S — Schema 5 min 

// No traditional schema — distributed cache is a key-value store.

// Key constraints:
// - Key: string, max 250 bytes
// - Value: bytes, max 1MB
// - TTL: long (seconds), 0 = no expiry

// Internal node data structure:
// CacheEntry { key, value, expiryMs (Long, nullable), prev, next (for LRU list) }

// Node topology — stored in ZooKeeper / etcd:
// /cache/nodes/{nodeId} = { "ip": "10.0.1.5", "port": 11211, "capacity": 107374182400 }

// Consistent hash ring — maintained in client library:
// TreeMap  (hash_point → node)
// Each physical node has 150 virtual nodes: hash("node_id#1") ... hash("node_id#150")

// Client routing (client-side, no proxy):
// 1. Hash the key → ring position
// 2. TreeMap.ceilingKey(hash) → nearest node clockwise
// 3. Send get/put directly to that node IP:port

🏗️ H — High-level Design 10 min

Figure: Consistent hash ring — key K maps clockwise to C2; removing C3 only migrates C3's key range to C4 (other nodes unaffected)

Components

  • Client Library: Embedded in every application server. Maintains a copy of the ring topology. Routes requests directly to the correct cache node — no proxy hop.
  • Cache Nodes: Stateless in terms of routing — each node only stores its own key space. In-memory hashmap + LRU doubly-linked list per node.
  • Config Service (ZooKeeper): Source of truth for node membership. Client library watches ZooKeeper for topology changes (node added/removed) and updates its ring.

Why Client-Side Routing?

A proxy (like Twemproxy) adds an extra network hop — doubles latency. Client-side routing keeps it at one hop: client → cache node. The cost: every client must maintain ring state (a TreeMap of ~15,000 entries = ~1MB per client).

🔬 D — Deep Dive: Consistent Hashing with Virtual Nodes 10 min

Why Not Simple Modulo Hashing?

hash(key) % numNodes — when you add a node, numNodes changes → almost every key remaps to a different node. A cache with 100 nodes adding 1 new node would invalidate ~99% of cached keys. Catastrophic for a cache.

Consistent Hashing

Imagine a ring of 2³² hash values (0 to ~4 billion). Each node maps to one or more points on the ring (virtual nodes). To find the node for a key: hash the key → find the nearest node clockwise on the ring. When you add a node, only the keys between the new node and its predecessor move. That's K/N keys (where K = total keys, N = nodes), or ~1% when adding the 101st node.

Virtual Nodes for Balance

Without virtual nodes, real nodes cluster unevenly on the ring. With 150 virtual nodes per physical node, the load distribution is near-uniform (within 5% per node).

⚖️ E — Evaluate 5 min

  • Node failure: If a node goes down, its keys become cache misses. Clients fall through to the database (cache is a performance optimization, not a source of truth). Replication (write to 2 nodes) reduces miss rate but doubles write cost.
  • Hot keys: A single key (e.g., a viral post) could overload one node. Solution: client-side replication for hot keys — write to N nodes, read from any. Or prefix-sharding: store the hot key as key#1, key#2, ... and round-robin reads.
  • LRU correctness: Each node runs its own LRU independently. Eviction is per-node, not global. This is correct — there's no cross-node LRU needed.

🚀 D — Deliver 2 min

"We use consistent hashing with 150 virtual nodes per physical node to distribute keys evenly across 100 cache nodes. Adding a node remaps only ~1% of keys instead of ~99%. Each node stores its key space in an LRU cache (ConcurrentHashMap + doubly-linked list). Client-side routing eliminates proxy hops. Node topology is managed by ZooKeeper and watched by client libraries for real-time ring updates."

⚖️ Key Trade-offs

DecisionOption AOption BWinner
Key Distribution Modulo hashing Consistent hashing with virtual nodes Consistent hashing — only K/N keys move on node add/remove
Routing Proxy (Twemproxy) Client-side library Client-side — saves one network hop; proxy is a SPOF and adds latency
Consistency Strong (synchronous replication) Eventual (async replication) Eventual — cache is a perf layer; stale reads are acceptable
Eviction Policy LRU (Least Recently Used) LFU (Least Frequently Used) LRU — simpler, most cache workloads are recency-biased; LFU better for skewed access patterns

☕ Java Implementation 

/**
 * ConsistentHashRouter — maps cache keys to cache nodes using a virtual node ring.
 * Uses MD5 hashing for good distribution. TreeMap provides O(log n) key lookup.
 */
public class ConsistentHashRouter {
    private static final int VIRTUAL_NODES_PER_PHYSICAL_NODE = 150;
    private final TreeMap hashRing = new TreeMap<>();
    private final Map nodesByNodeId = new HashMap<>();

    /**
     * Adds a physical cache node to the ring with VIRTUAL_NODES_PER_PHYSICAL_NODE virtual points.
     *
     * @param cacheNode The physical cache node to add
     */
    public synchronized void addNode(CacheNode cacheNode) {
        nodesByNodeId.put(cacheNode.getNodeId(), cacheNode);
        for (int virtualIndex = 0; virtualIndex < VIRTUAL_NODES_PER_PHYSICAL_NODE; virtualIndex++) {
            long ringPosition = hashToLong(cacheNode.getNodeId() + "#" + virtualIndex);
            hashRing.put(ringPosition, cacheNode);
        }
    }

    /**
     * Removes a physical node and all its virtual nodes from the ring.
     *
     * @param nodeId The ID of the node to remove
     */
    public synchronized void removeNode(String nodeId) {
        nodesByNodeId.remove(nodeId);
        for (int virtualIndex = 0; virtualIndex < VIRTUAL_NODES_PER_PHYSICAL_NODE; virtualIndex++) {
            long ringPosition = hashToLong(nodeId + "#" + virtualIndex);
            hashRing.remove(ringPosition);
        }
    }

    /**
     * Returns the cache node responsible for the given key.
     * Finds the nearest node clockwise on the ring.
     *
     * @param key The cache key to route
     * @return The CacheNode that owns this key
     * @throws IllegalStateException if no nodes are registered
     */
    public CacheNode getNodeForKey(String key) {
        if (hashRing.isEmpty()) {
            throw new IllegalStateException("No cache nodes registered in the ring");
        }
        long keyHash = hashToLong(key);
        Map.Entry entry = hashRing.ceilingEntry(keyHash);
        // Wrap around — if no node clockwise from keyHash, take the first node on the ring
        if (entry == null) {
            entry = hashRing.firstEntry();
        }
        return entry.getValue();
    }

    public int getRingSize() { return hashRing.size(); }
    public int getNodeCount() { return nodesByNodeId.size(); }

    private long hashToLong(String input) {
        try {
            MessageDigest md5Digest = MessageDigest.getInstance("MD5");
            byte[] digestBytes = md5Digest.digest(input.getBytes(StandardCharsets.UTF_8));
            // Take first 8 bytes of MD5 output → long
            long hashValue = 0;
            for (int byteIndex = 0; byteIndex < 8; byteIndex++) {
                hashValue = (hashValue << 8) | (digestBytes[byteIndex] & 0xFF);
            }
            return hashValue;
        } catch (NoSuchAlgorithmException algorithmException) {
            throw new RuntimeException("MD5 not available", algorithmException);
        }
    }
}

/**
 * LRUCache — per-node in-memory LRU cache using ConcurrentHashMap + doubly-linked list.
 * Thread-safe for concurrent get/put/delete from multiple client connections.
 */
public class LRUCache {
    private final int maxCapacityBytes;
    private volatile int currentUsedBytes = 0;
    private final Map cacheMap;
    private final CacheEntry lruHead;  // Dummy head (most recently used side)
    private final CacheEntry lruTail;  // Dummy tail (least recently used side)
    private final ReentrantReadWriteLock cacheLock = new ReentrantReadWriteLock();

    public LRUCache(int maxCapacityBytes) {
        this.maxCapacityBytes = maxCapacityBytes;
        this.cacheMap = new ConcurrentHashMap<>();
        this.lruHead = new CacheEntry("__head__", null, 0, Long.MAX_VALUE);
        this.lruTail = new CacheEntry("__tail__", null, 0, Long.MAX_VALUE);
        lruHead.next = lruTail;
        lruTail.prev = lruHead;
    }

    /**
     * Returns the cached value for the key, or null if missing or expired.
     * Moves the accessed entry to the MRU (head) position.
     */
    public byte[] get(String key) {
        cacheLock.writeLock().lock(); // Write lock because we update LRU position
        try {
            CacheEntry entry = cacheMap.get(key);
            if (entry == null) {
                return null;
            }
            if (isExpired(entry)) {
                removeEntry(entry);
                return null;
            }
            moveToHead(entry); // Mark as most recently used
            return entry.getValue();
        } finally {
            cacheLock.writeLock().unlock();
        }
    }

    /**
     * Stores a key-value pair with optional TTL.
     * Evicts LRU entries if capacity is exceeded.
     */
    public void put(String key, byte[] value, long ttlSeconds) {
        cacheLock.writeLock().lock();
        try {
            long expiryMs = ttlSeconds > 0
                    ? System.currentTimeMillis() + ttlSeconds * 1000L
                    : Long.MAX_VALUE;
            int entryBytes = key.getBytes(StandardCharsets.UTF_8).length + value.length;

            // Update existing entry
            CacheEntry existingEntry = cacheMap.get(key);
            if (existingEntry != null) {
                currentUsedBytes -= existingEntry.getSizeBytes();
                existingEntry.setValue(value);
                existingEntry.setExpiryMs(expiryMs);
                existingEntry.setSizeBytes(entryBytes);
                currentUsedBytes += entryBytes;
                moveToHead(existingEntry);
                return;
            }

            // Evict until there's room
            while (currentUsedBytes + entryBytes > maxCapacityBytes && lruTail.prev != lruHead) {
                CacheEntry lruEntry = lruTail.prev;
                removeEntry(lruEntry);
            }

            CacheEntry newEntry = new CacheEntry(key, value, entryBytes, expiryMs);
            cacheMap.put(key, newEntry);
            addToHead(newEntry);
            currentUsedBytes += entryBytes;
        } finally {
            cacheLock.writeLock().unlock();
        }
    }

    public void delete(String key) {
        cacheLock.writeLock().lock();
        try {
            CacheEntry entry = cacheMap.get(key);
            if (entry != null) {
                removeEntry(entry);
            }
        } finally {
            cacheLock.writeLock().unlock();
        }
    }

    public int getKeyCount() { return cacheMap.size(); }
    public int getCurrentUsedBytes() { return currentUsedBytes; }

    private boolean isExpired(CacheEntry entry) {
        return System.currentTimeMillis() > entry.getExpiryMs();
    }

    private void addToHead(CacheEntry entry) {
        entry.next = lruHead.next;
        entry.prev = lruHead;
        lruHead.next.prev = entry;
        lruHead.next = entry;
    }

    private void removeFromList(CacheEntry entry) {
        entry.prev.next = entry.next;
        entry.next.prev = entry.prev;
    }

    private void moveToHead(CacheEntry entry) {
        removeFromList(entry);
        addToHead(entry);
    }

    private void removeEntry(CacheEntry entry) {
        removeFromList(entry);
        cacheMap.remove(entry.getKey());
        currentUsedBytes -= entry.getSizeBytes();
    }

    /**
     * Internal node for the LRU doubly-linked list.
     */
    private static class CacheEntry {
        private final String key;
        private byte[] value;
        private int sizeBytes;
        private long expiryMs;
        CacheEntry prev;
        CacheEntry next;

        CacheEntry(String key, byte[] value, int sizeBytes, long expiryMs) {
            this.key = key;
            this.value = value;
            this.sizeBytes = sizeBytes;
            this.expiryMs = expiryMs;
        }

        public String getKey() { return key; }
        public byte[] getValue() { return value; }
        public void setValue(byte[] value) { this.value = value; }
        public int getSizeBytes() { return sizeBytes; }
        public void setSizeBytes(int sizeBytes) { this.sizeBytes = sizeBytes; }
        public long getExpiryMs() { return expiryMs; }
        public void setExpiryMs(long expiryMs) { this.expiryMs = expiryMs; }
    }
}
