Tier 1 — Must Know 45 min Infrastructure

Design a Rate Limiter

Every API at every MAANG company uses one. Interviewers love this because it tests algorithm knowledge (5 algorithms), distributed systems thinking, and the edge case of race conditions under concurrent load.

🏢 Google, Amazon, Stripe, Cloudflare
⏱️ 45 min interview
⚡ <1ms latency budget

❓ R — Requirements 3–5 min

Functional Requirements

  • Limit requests per user/IP/API key to N requests per time window (configurable)
  • Return HTTP 429 Too Many Requests with Retry-After header when exceeded
  • Support multiple simultaneous limits: e.g., 100/minute AND 1000/day
  • Different limits per tier: free (10/min), pro (100/min), enterprise (1000/min)

Non-Functional Requirements

  • Latency: Add < 1ms to every request (cannot be the bottleneck)
  • Availability: 99.9% — if rate limiter is down, fail open (pass the request through)
  • Distributed: Must work correctly across 50 API server nodes — no node-local counter
  • Accuracy: Cannot allow more than N+ε requests (small tolerance acceptable)
Crucial to clarify: Should failure be fail-open (allow request) or fail-closed (reject request)? For revenue-generating APIs, fail-open is almost always right — you'd rather allow a few extra requests than block paying customers because Redis is down.

🔢 E — Estimation 5 min

  • Throughput: 100K QPS through rate limiter middleware
  • Active users: 1M → 1M counters in Redis
  • Memory per counter (fixed window): ~50 bytes per key → 50MB total — trivial for Redis
  • Memory per counter (sliding window log): 100 timestamps × 8 bytes × 1M users = ~800MB — manageable
  • Redis INCR latency: ~0.1ms per operation — well within the 1ms budget
  • Lua script overhead: ~0.2ms — still within budget

// Plans: { "free": 10, "pro": 100, "enterprise": 1000 }  (per minute)

🏗️ H — High-level Design 10 min

Placement: API Gateway Middleware

Rate limiter runs as middleware in the API Gateway — before the request reaches any application logic. This ensures rejected requests cost the minimum compute.

Request Flow

  1. Request arrives at API Gateway
  2. Middleware extracts rate limit key (user_id / API key / IP)
  3. Look up user's plan → get limit configuration
  4. Execute atomic Redis operation (Lua script) to check + increment counter
  5. If within limit: pass request to downstream service; set X-RateLimit-Remaining header
  6. If over limit: return 429 with Retry-After: {seconds} header

Distributed Accuracy

All 50 nodes share a single Redis cluster — no node-local state. This guarantees correct counts across the entire fleet. The trade-off: every request adds one Redis round-trip (~0.1ms). Within the 1ms budget.

🔬 D — Deep Dive: Algorithms and Atomicity 10 min

The 5 Algorithms (Know All of Them)

  1. Fixed Window Counter: Count resets at window boundary. Simple. Problem: burst at window boundary (send 100 at 00:59, 100 at 01:01 = 200 in 2 seconds).
  2. Sliding Window Log: Store timestamp of every request. Count entries within last window_size. Exact accuracy. Problem: memory scales with limit size.
  3. Sliding Window Counter: Blend current and previous window counts weighted by time overlap. Good accuracy, low memory.
  4. Token Bucket: Bucket refills at rate R tokens/sec. Max capacity C. Each request consumes one token. Allows short bursts up to C. Used by AWS API Gateway.
  5. Leaky Bucket: Requests queue; processed at fixed rate. Smooth output. Problem: bursty requests queue up and may expire.

Race Condition: Why You Need a Lua Script

Two requests arrive simultaneously. Both read count=99 (limit=100). Both think they're the 100th request. Both write count=100. You've allowed 101 requests. Fix: use a Redis Lua script that atomically checks-and-increments in one operation — Redis is single-threaded, so Lua scripts are always atomic.

⚖️ E — Evaluate 5 min

  • Redis failure: Fail open — let all requests through. Log the failure. Alert on duty. Do not cascade a Redis outage into an API outage.
  • Redis latency spike: Set a 2ms timeout on Redis calls. If timeout, fail open.
  • Multiple limit tiers: Run two Redis commands — one per-minute check, one per-day check. If either fails, block. Lua script can check both atomically.
  • Distributed Redis cluster: Use consistent hashing to route each user's key to the same Redis shard — avoids split-brain counting.

🚀 D — Deliver 2 min

"We implement a sliding window log using Redis sorted sets, executed atomically via Lua script to prevent race conditions. All 50 API Gateway nodes share a Redis cluster, giving consistent distributed counts. The rate limiter adds ~0.2ms per request (well within the 1ms budget). On Redis failure, we fail open to prevent availability impact. 429 responses include Retry-After headers for client backoff."

☕ Java Implementation 

/**
 * SlidingWindowRateLimiter — implements sliding window log using Redis sorted sets.
 * Uses a Lua script for atomic check-and-record to prevent race conditions.
 */
public class SlidingWindowRateLimiter {
    private static final String KEY_PREFIX = "rl:log:";

    // Lua script: atomically removes expired entries, counts current, conditionally adds new.
    // Returns 1 if allowed, 0 if rejected.
    private static final String SLIDING_WINDOW_LUA_SCRIPT = """
        local key = KEYS[1]
        local now = tonumber(ARGV[1])
        local window_start = tonumber(ARGV[2])
        local limit = tonumber(ARGV[3])
        local request_id = ARGV[4]
        local window_ttl = tonumber(ARGV[5])

        -- Remove entries outside the window
        redis.call('ZREMRANGEBYSCORE', key, '-inf', window_start)

        -- Count current entries in window
        local count = redis.call('ZCARD', key)

        if count < limit then
            -- Add this request's timestamp to the log
            redis.call('ZADD', key, now, request_id)
            -- Reset TTL on the key
            redis.call('EXPIRE', key, window_ttl)
            return 1  -- allowed
        else
            return 0  -- rejected
        end
        """;

    private final RedisClient redisClient;
    private final int requestsPerWindow;
    private final long windowDurationMs;

    public SlidingWindowRateLimiter(RedisClient redisClient,
                                    int requestsPerWindow,
                                    long windowDurationMs) {
        this.redisClient = redisClient;
        this.requestsPerWindow = requestsPerWindow;
        this.windowDurationMs = windowDurationMs;
    }

    /**
     * Checks if a request is allowed and records it if so.
     *
     * @param rateLimitKey  The identifier: userId, API key, or IP
     * @return RateLimitResult indicating allowed/blocked and remaining count
     */
    public RateLimitResult checkAndRecord(String rateLimitKey) {
        String redisKey = KEY_PREFIX + rateLimitKey;
        long nowMs = System.currentTimeMillis();
        long windowStartMs = nowMs - windowDurationMs;
        String requestId = UUID.randomUUID().toString();
        long windowTtlSeconds = windowDurationMs / 1000 + 1;

        try {
            long scriptResult = redisClient.evalLua(
                    SLIDING_WINDOW_LUA_SCRIPT,
                    List.of(redisKey),
                    List.of(
                            String.valueOf(nowMs),
                            String.valueOf(windowStartMs),
                            String.valueOf(requestsPerWindow),
                            requestId,
                            String.valueOf(windowTtlSeconds)
                    )
            );

            boolean isAllowed = scriptResult == 1L;
            long currentCount = isAllowed
                    ? redisClient.zcard(redisKey)
                    : requestsPerWindow;
            long remaining = Math.max(0, requestsPerWindow - currentCount);
            long resetAtMs = nowMs + windowDurationMs;

            return new RateLimitResult(isAllowed, remaining, requestsPerWindow, resetAtMs);

        } catch (RedisException redisException) {
            // Fail open — Redis unavailable, allow the request
            System.err.println("[SlidingWindowRateLimiter] Redis error, failing open: "
                    + redisException.getMessage());
            return RateLimitResult.failOpen(requestsPerWindow);
        }
    }
}

/**
 * TokenBucketRateLimiter — allows burst traffic up to bucket capacity.
 * Tokens refill at a fixed rate. Each request consumes one token.
 */
public class TokenBucketRateLimiter {
    private static final String KEY_PREFIX = "rl:token:";

    private final RedisClient redisClient;
    private final int bucketCapacity;          // Max tokens (burst size)
    private final double refillRatePerSecond;  // Tokens added per second

    public TokenBucketRateLimiter(RedisClient redisClient,
                                  int bucketCapacity,
                                  double refillRatePerSecond) {
        this.redisClient = redisClient;
        this.bucketCapacity = bucketCapacity;
        this.refillRatePerSecond = refillRatePerSecond;
    }

    /**
     * Attempts to consume one token from the bucket.
     * Uses compare-and-swap with Redis WATCH for optimistic locking.
     *
     * @param rateLimitKey The user or API key identifier
     * @return true if a token was available (request allowed), false otherwise
     */
    public boolean tryConsume(String rateLimitKey) {
        String redisKey = KEY_PREFIX + rateLimitKey;
        long nowMs = System.currentTimeMillis();

        for (int attempt = 0; attempt < 3; attempt++) {
            try {
                BucketState currentState = getBucketState(redisKey, nowMs);
                double tokensAfterRefill = calculateTokensAfterRefill(currentState, nowMs);

                if (tokensAfterRefill < 1.0) {
                    return false; // No tokens available
                }

                double tokensAfterConsume = tokensAfterRefill - 1.0;
                boolean saved = saveBucketState(redisKey, tokensAfterConsume, nowMs);

                if (saved) {
                    return true;
                }
                // CAS failed — retry (another request modified the bucket concurrently)

            } catch (RedisException redisException) {
                System.err.println("[TokenBucketRateLimiter] Redis error, failing open: "
                        + redisException.getMessage());
                return true; // Fail open
            }
        }
        // All CAS retries exhausted — treat as throttled to be safe
        return false;
    }

    private BucketState getBucketState(String redisKey, long nowMs) {
        Map bucketHash = redisClient.hgetall(redisKey);
        if (bucketHash.isEmpty()) {
            // First request for this key — initialize full bucket
            return new BucketState(bucketCapacity, nowMs);
        }
        double tokens = Double.parseDouble(bucketHash.get("tokens"));
        long lastRefillMs = Long.parseLong(bucketHash.get("lastRefillMs"));
        return new BucketState(tokens, lastRefillMs);
    }

    private double calculateTokensAfterRefill(BucketState state, long nowMs) {
        long elapsedMs = nowMs - state.getLastRefillMs();
        double tokensToAdd = elapsedMs / 1000.0 * refillRatePerSecond;
        return Math.min(bucketCapacity, state.getTokens() + tokensToAdd);
    }

    private boolean saveBucketState(String redisKey, double tokens, long nowMs) {
        // Use Redis WATCH + MULTI/EXEC for optimistic locking
        return redisClient.watchedMultiExec(redisKey, () -> {
            redisClient.hset(redisKey, "tokens", String.valueOf(tokens));
            redisClient.hset(redisKey, "lastRefillMs", String.valueOf(nowMs));
            redisClient.expire(redisKey, 3600); // 1 hour TTL for inactive users
        });
    }
}

/**
 * RateLimitResult — immutable result of a rate limit check.
 */
public final class RateLimitResult {
    private final boolean allowed;
    private final long remaining;
    private final long limit;
    private final long resetAtMs;

    public RateLimitResult(boolean allowed, long remaining, long limit, long resetAtMs) {
        this.allowed = allowed;
        this.remaining = remaining;
        this.limit = limit;
        this.resetAtMs = resetAtMs;
    }

    public static RateLimitResult failOpen(long limit) {
        return new RateLimitResult(true, limit, limit, System.currentTimeMillis() + 60_000L);
    }

    public boolean isAllowed() { return allowed; }
    public long getRemaining() { return remaining; }
    public long getLimit() { return limit; }
    public long getResetAtMs() { return resetAtMs; }
    public long getRetryAfterSeconds() {
        return Math.max(0, (resetAtMs - System.currentTimeMillis()) / 1000);
    }
}
