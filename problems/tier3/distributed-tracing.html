Design a Distributed Tracing System (like Jaeger)

Distributed tracing answers why was this specific request slow across dozens of microservices. The key challenge: you cannot trace everything (too expensive), but random 1% sampling misses the rare slow outliers you most need to find. Adaptive sampling solves this.

🏢 Jaeger, Zipkin, Datadog APM
⏱️ 60 min interview

❓R — Requirements3–5 min

Functional Requirements

  • Trace a single request end-to-end across microservices
  • Visualize spans (service calls) with timing and metadata
  • Search traces by service, latency, error, or custom tags
  • Alert on SLO violations (p99 latency > threshold)

Non-Functional Requirements

  • Scale: 100K requests/sec, 1M spans/sec
  • Sampling overhead: <1% on traced services
  • Retention: Last 7 days queryable; compress and archive older

🔢E — Estimation3–5 min

  • 1M spans/sec × 500 bytes/span = 500MB/sec = 43TB/day → with 1% sampling: 430GB/day
  • Span search index (service, tags) for search: 10% of raw size = 43GB/day → Elasticsearch handles this

🗄️S — Schema3–5 min

// Trace storage (Cassandra -- partition by traceId for O(1) trace lookup)
spans:
    trace_id     UUID,         -- same across all spans in one request
    span_id      UUID,
    parent_span  UUID,         -- null for root span

    operation    VARCHAR(100),
    start_time   TIMESTAMP,
    duration_us  INT,          -- microseconds
    tags         MAP,
    status       ENUM(ok, error),
    PRIMARY KEY (trace_id, span_id)

// Span index (Elasticsearch -- for search: find traces by service/latency/tag)
// Indexes: service, duration_us, status, tags.*

🏗️H — High-level Design10 min

  • Instrumentation: OpenTelemetry SDK in each service. Creates spans for outbound calls. Injects trace context into HTTP headers (W3C traceparent: 00-{traceId}-{spanId}-{flags}).
  • Sampling decision: Made at trace root (head-based) or after trace completes (tail-based). Propagated to all downstream services via sampled flag in traceparent.
  • Span collector: Agents in each pod batch spans and send to Kafka. Collector consumers write to Cassandra (by trace_id) and index to Elasticsearch.
  • Trace assembly: Query Cassandra with trace_id → get all spans → build tree by parent_span linkage.
  • UI: Gantt chart timeline, service dependency graph, latency histograms.

🔬D — Deep Dive10 min

Head-based sampling: Sampling decision made at trace root (first service). Propagated downstream via traceparent sampled flag (1=sample, 0=drop). Simple, predictable overhead, but cannot sample based on outcome -- you do not know if the trace will be slow until it is complete.

Tail-based sampling: All spans buffered in-memory. Sampling decision made when trace is complete. Can use trace characteristics: is it slow? Did it have errors? This is the correct approach for capturing outliers -- slow traces are captured at higher rates than fast ones.

Adaptive sampling: Start with 1% base rate. If a trace has p99 latency > threshold, upgrade to 100% sample rate for that trace. Slow traces and error traces are always written; fast normal traces are sampled probabilistically.

W3C Traceparent header format:

traceparent: 00-{16-byte traceId}-{8-byte spanId}-{flags}

Flags byte: 0x01 = sampled. Services check this flag before creating child spans.

✅E — Evaluate3 min

  • Head-based vs tail-based trade-off: Head-based: zero buffering, simple. Tail-based: requires buffering all spans (memory-intensive), complex. For debugging production issues, tail-based is far more valuable -- you can guarantee slow/error traces are captured.
  • Storage cost: Even at 1% sampling, 7-day retention requires ~3TB of span data + 300GB Elasticsearch index. Manageable but requires dedicated cluster separate from application Elasticsearch.

🚀D — Deliver2 min

Distributed tracing = W3C traceparent propagation + adaptive tail-based sampling + Cassandra storage (by trace_id) + Elasticsearch index (by service/latency/tags). Key insight: always capture error traces and slow traces regardless of base sample rate.

⚖️Trade-offs

DecisionHead-based SamplingTail-based Sampling
When to decideAt trace root (start)After trace completes (end)
Can capture slow outliersNo -- decision before outcome knownYes -- decision after duration known
Memory overheadNone -- spans dropped immediatelyHigh -- all spans buffered until trace complete
Implementation complexityLowHigh -- consistent hashing by traceId required

☕Java Implementation

/**
 * TraceSampler -- adaptive sampling that ensures slow/error traces are always captured.
 * Base sampling rate: 1%. Traces exceeding latency threshold: 100% sampled.
 */
public class TraceSampler {

    private static final double BASE_SAMPLE_RATE = 0.01; // 1% default
    private static final long SLOW_TRACE_THRESHOLD_MS = 500; // 500ms = slow
    private static final String SAMPLED_FLAG = "01";
    private static final String NOT_SAMPLED_FLAG = "00";

    private final Random random = new Random();

    /**
     * Decides whether to sample a completed trace.
     * Prioritizes: (1) error traces, (2) slow traces, (3) probabilistic base rate.
     */
    public boolean shouldSample(String traceId, long durationMs, boolean hasErrors) {
        if (hasErrors) {
            return true; // Always sample error traces for debugging
        }
        if (durationMs > SLOW_TRACE_THRESHOLD_MS) {
            return true; // Always sample slow traces for performance analysis
        }
        return random.nextDouble() < BASE_SAMPLE_RATE;
    }

    /**
     * Generates W3C traceparent header for a new root span.
     */
    public String generateTraceparent(String traceId, String spanId, boolean sampledDecision) {
        String sampledFlag = sampledDecision ? SAMPLED_FLAG : NOT_SAMPLED_FLAG;
        return "00-" + traceId + "-" + spanId + "-" + sampledFlag;
    }

    /**
     * Parses a traceparent header to extract trace context.
     * Called by downstream services to continue the trace.
     */
    public TraceContext parseTraceparent(String traceparentHeader) {
        if (traceparentHeader == null || traceparentHeader.isEmpty()) {
            return TraceContext.newTrace(BASE_SAMPLE_RATE);
        }
        String[] parts = traceparentHeader.split("-");
        if (parts.length < 4) {
            return TraceContext.newTrace(BASE_SAMPLE_RATE);
        }
        boolean isSampled = SAMPLED_FLAG.equals(parts[3]);
        return new TraceContext(parts[1], parts[2], isSampled);
    }

    public record TraceContext(String traceId, String parentSpanId, boolean isSampled) {
        static TraceContext newTrace(double sampleRate) {
            return new TraceContext(
                UUID.randomUUID().toString().replace("-", ""),
                null,
                Math.random() < sampleRate
            );
        }
    }
}
