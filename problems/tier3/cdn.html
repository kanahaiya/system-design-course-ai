Tier 3 — Expert 60 minInfrastructure / Networking

Design a CDN (Content Delivery Network)

A CDN is architecturally simple (it is a cache layer at the edge) but operationally complex. The interesting interview questions: anycast routing so all PoPs share one IP, origin shields so cache misses do not hammer origin, and cache invalidation at global scale.

🏢 Cloudflare, Akamai, AWS CloudFront
⏱️ 60 min interview

❓R — Requirements3–5 min

Functional Requirements

  • Cache static content (images, JS, CSS, video segments) at edge nodes globally
  • Route users to the nearest/fastest PoP (Point of Presence)
  • Cache invalidation: purge content across all PoPs after origin update
  • SSL termination at edge
  • DDoS protection and rate limiting at edge

Non-Functional Requirements

  • Scale: 100TB cached content, 10M requests/sec across PoPs
  • Latency: <10ms additional latency at edge vs <150ms to origin
  • Cache hit rate: >95% for cacheable content

🔢E — Estimation3–5 min

  • 100 PoPs worldwide × 10TB storage each = 1PB CDN storage
  • 10M req/sec × avg 100KB response = 1 Tbps egress bandwidth
  • Cache invalidation: 1M URLs × 100 PoPs = 100M invalidation messages per deploy

🏗️H — High-level Design10 min

  • Anycast routing: All PoPs announce the same IP prefix via BGP. User DNS resolves to CDN IP; BGP routes their TCP connection to the nearest PoP by AS-path topology.
  • Pull CDN (lazy): Edge PoP receives miss, requests from origin shield, shield misses go to origin. First user gets higher latency; subsequent users get cached response.
  • Push CDN (proactive): New content deployed to origin, CDN push API broadcasts to all PoPs. Good for large files (video), popular content known in advance.
  • Origin shield: All PoP misses go to a regional shield tier before origin. If 1,000 PoPs simultaneously miss the same URL, only the shield(s) hit origin — 1,000× reduction in origin load.
  • Cache invalidation: Content version in URL (cache-busting). Or CDN purge API: broadcast purge message to all PoPs via internal pub/sub.

// 5. Shield MISS -> request from origin -> cache at shield -> cache at PoP -> return

🔬D — Deep Dive10 min

Anycast routing deep dive:

Anycast = same IP address advertised from multiple locations. When a user's DNS resolves cdn.example.com to 1.2.3.4, BGP routes their packets to whichever AS (autonomous system) announces 1.2.3.4 with the shortest AS-path. This naturally selects the closest PoP.

Benefits: No per-user geographic routing logic. BGP handles failover automatically (if a PoP goes down, BGP withdraws its announcement, traffic reroutes to next-nearest).

Cache hit rate optimization:

  • Cache key normalization: strip non-meaningful query params, lowercase URLs
  • Vary header handling: if origin returns Vary: Accept-Encoding, cache separate versions for gzip vs brotli
  • Long TTL for versioned assets (max-age=31536000 for /static/app.v3.js)
  • Short TTL or no-cache for personalized content

Stale-while-revalidate: Serve stale cached content immediately while fetching fresh content in the background. User gets fast response, content gets updated asynchronously. The best of both worlds for content that can tolerate slight staleness.

✅E — Evaluate3 min

  • Cache invalidation at scale: Purging 1M URLs × 100 PoPs = 100M messages. Use hierarchical invalidation: PoPs subscribe to regional invalidation channel; regional shield subscribes to global channel.
  • Thundering herd on popular content expiry: All PoPs simultaneously expire the same popular item. Mitigation: staggered TTL (add random jitter), or serve stale while revalidating in background (SWR pattern).

🚀D — Deliver2 min

Summary: CDN = anycast routing + tiered cache (edge → shield → origin) + cache invalidation via versioned URLs (preferred) or purge API. Key insight: origin shield multiplies cache hit rate by aggregating misses across PoPs.

⚖️Trade-offs

DecisionOption AOption B
CDN strategyPull CDN: lazy, low cost, cold start latencyPush CDN: proactive, no cold start, storage overhead
Cache invalidationURL versioning (cache-busting): zero invalidation cost, requires build toolingPurge API: flexible, high invalidation cost at scale
RoutingAnycast: automatic, no routing logic, BGP convergence delay on failoverGeoDNS: configurable, requires DNS record management per region
TTLLong TTL (1 year): best hit rate, stale risk on updatesShort TTL (5 min): always fresh, more origin load

☕Java Implementation

/**
 * OriginShieldProxy -- implements tiered cache hierarchy.
 * Edge -> Shield -> Origin. Reduces origin load by aggregating misses per region.
 */
public class OriginShieldProxy {
    private final Map<String, CachedEntry> localCache = new ConcurrentHashMap<>();
    private final OriginShieldProxy regionShield;  // null if this IS the shield
    private final OriginClient originClient;

    public OriginShieldProxy(OriginShieldProxy regionShield, OriginClient originClient) {
        this.regionShield = regionShield;
        this.originClient = originClient;
    }

    /**
     * Serves a request from cache, regional shield, or origin.
     * Implements stale-while-revalidate: serve stale immediately, refresh async.
     */
    public CachedResponse serve(String cacheKey) {
        CachedEntry localEntry = localCache.get(cacheKey);

        if (localEntry != null && !localEntry.isExpired()) {
            return CachedResponse.fromCache(localEntry.getContent(), "HIT");
        }

        if (localEntry != null && localEntry.isStaleWithinGracePeriod()) {
            // Serve stale, refresh async (stale-while-revalidate)
            refreshAsync(cacheKey);
            return CachedResponse.fromCache(localEntry.getContent(), "STALE");
        }

        // Cache miss -- request from regional shield (or origin if we are the shield)
        CachedResponse upstreamResponse = fetchFromUpstream(cacheKey);
        if (upstreamResponse.isCacheable()) {
            localCache.put(cacheKey, new CachedEntry(
                upstreamResponse.getContent(),
                System.currentTimeMillis() + upstreamResponse.getTtlMs(),
                upstreamResponse.getTtlMs() + 30_000  // 30s grace period for stale
            ));
        }
        return upstreamResponse;
    }

    private CachedResponse fetchFromUpstream(String cacheKey) {
        if (regionShield != null) {
            return regionShield.serve(cacheKey);  // ask regional shield
        }
        return originClient.fetch(cacheKey);  // we are the shield -- go to origin
    }

    private void refreshAsync(String cacheKey) {
        Thread.ofVirtual().start(() -> {
            CachedResponse freshContent = fetchFromUpstream(cacheKey);
            if (freshContent.isCacheable()) {
                localCache.put(cacheKey, new CachedEntry(
                    freshContent.getContent(),
                    System.currentTimeMillis() + freshContent.getTtlMs(),
                    freshContent.getTtlMs() + 30_000
                ));
            }
        });
    }
}
